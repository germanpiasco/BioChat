# BioChat Web 0.5

## Nuevo
- Calendario mensual con días que tienen registros.
- Objetivos configurables: proteína, sesiones, peso de referencia y cintura.
- Progresión por ejercicio comparando series con RIR ±1.
- Indicador porcentual de mejora estimada.
- Fotos frente/perfil/espalda guardadas localmente con IndexedDB.
- Mantiene comparación semanal, volumen muscular, nutrición, recuperación y backups.
- Migra datos locales desde 0.3/0.4 si comparte el mismo origen.

## Importante
Las fotos permanecen en el dispositivo y no se incluyen aún en el respaldo JSON.
La estimación de progresión usa una fórmula simple de rendimiento y no sustituye la lectura del contexto de cada sesión.

## Próximo objetivo
Publicación HTTPS/PWA, historial por día seleccionable, fotos comparables por fecha y pulido para uso diario en iPhone.
